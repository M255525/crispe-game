# CRISPE 卡牌配對

依 CRISPE 提示詞框架設計的拖放卡牌配對練習遊戲，純前端實作，無需安裝，開啟即玩。

**線上遊玩**：<https://m255525.github.io/crispe-game/>

---

## 快速開始

直接用瀏覽器開啟 `index.html`，即可開始遊戲。無需伺服器、無需安裝任何套件（頂部跑馬燈公告需要網路，其餘功能離線可玩）。

---

## 這是什麼？

一個拖放卡牌小遊戲，用來練習 **CRISPE 提示詞框架**的分類邏輯——每局隨機抽出 5 個生活化情境，把描述句拖進正確的提示格，藉此熟悉「角色與能力」「背景洞察」「具體任務」「語氣與風格」「限制與條件」這五個維度該怎麼拆解。與姊妹專案「提示詞控制台」（負責「產生」提示詞）互補——這裡是「練習」分類判斷力。

---

## CRISPE 五個提示格

| 代號 | 名稱 |
|------|------|
| CR | 角色與能力 |
| I | 背景洞察 |
| S | 具體任務 |
| P | 語氣與風格 |
| E | 限制與條件 |

卡牌文字刻意不含「角色」「任務」這類關鍵字提示，需要理解語意才能正確分類。

---

## 玩法說明

1. 按右上角「▶ 開始」開始計時，才能點選主題進入挑戰
2. 選一個主題卡片，畫面下方會出現這個情境的 5 張手牌（隨機洗亂）
3. 把每張卡拖進上方正確的提示格（滑鼠或觸控皆可），5 格全部放滿後「✔ 確認」按鈕才會亮起
4. 按「✔ 確認」判分：答對的格子亮綠、答錯的亮紅，每答對一格得 4 分（滿分 20 分／主題），隨後自動彈出正確答案核對頁
5. 5 個主題不分先後，可任意順序挑戰、重複挑戰；全部確認過後按「🏁 完成」看總結算
6. 5 個主題全數答對且拿下滿分 100 分，會出現恭賀畫面＋彩帶動畫

題庫共 **20 組虛構情境**，每局隨機抽出其中 5 組。

---

## 排行榜與成績分享

- **本機排行榜（前 10 名）**：結算畫面若總分擠得進前 10 名，會出現暱稱輸入框，記錄成績；右上角「🏆 排行榜」隨時可查看目前排名。
- **下載成績圖**：結算畫面按「💾 下載成績圖」，會用 Canvas 手繪一張成績卡片圖片並下載（不依賴任何外部套件）。
- **分享成績**：支援 Web Share API 的瀏覽器（多數手機瀏覽器）會顯示「📤 分享成績」，可直接分享成績圖到 LINE、社群等 App。

排行榜與成績都只存在瀏覽器本機 `localStorage`，不會跨裝置同步。

---

## 加入主畫面

主題選單畫面按「📲 加入主畫面」，可把遊戲安裝到手機或電腦桌面，之後不需開瀏覽器輸網址即可直接開啟。Android／桌面 Chrome 會直接跳出安裝視窗；iOS Safari 需透過「分享」→「加入主畫面」；Mac 桌面版 Safari 需透過「檔案」→「加入 Dock」。

---

## 響應式版面（RWD）

已在 320px（iPhone SE 等窄螢幕）到桌機寬度間實測，提示格、卡牌與按鈕會依螢幕寬度自動調整排列，不會產生水平捲動。

---

## 技術規格

- 純 HTML / CSS / JavaScript，單一檔案（`index.html`），無框架、無建置步驟
- 拖曳邏輯以 Pointer Events 自製，同時支援滑鼠與觸控
- 音效為 WebAudio 即時合成，無外部音檔
- 成績圖以 Canvas API 手繪產生，無外部圖片處理套件
- 支援 PWA 加入主畫面（`manifest.json` + `service-worker.js`）
- 相容 Chrome、Edge、Firefox、Safari 等主流瀏覽器
